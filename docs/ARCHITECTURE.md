# Architecture

## Runtime shape

```text
index.html (HUD, overlays, modals, mixer)
  ├─ Google Fonts stylesheet            remote
  ├─ three@0.128.0/three.min.js         remote
  ├─ three@0.128.0/OrbitControls.js     remote
  ├─ style.css?v=1.4.7                  local
  └─ script.js?v=1.4.7                  local
       └─ one IIFE, one `state` object, ~4,983 lines
audio/th/*.m4a                          145 local Thai PA clips
```

`script.js` is not modularised; it is a single closure. The only exports are the debug surface `window.__BTS__`, the error array `window.__BTS_ERRORS`, and the self-test result `window.__BTS_TEST__`. There is no build step, no npm package and no service worker.

## Boot sequence

`boot()` runs on `DOMContentLoaded` (or immediately if the document is already parsed):

```text
cacheDom()
  → set #versionLabel / #buildBadge from VERSION = '1.4.7'
  → if THREE is undefined: showBootError('Three.js could not be loaded…') and stop
  → initThree()
      scene, fog, PerspectiveCamera(62°, near 0.08, far 24000)
      WebGLRenderer: antialias, logarithmicDepthBuffer, pixelRatio ≤ 1.5,
                     sRGB, ACESFilmic, exposure 0.76, shadows off
      OrbitControls: damping 0.06, no pan, distance 8–220, maxPolar 0.495π
      sky ShaderMaterial dome (14,000 radius), sun sprite, 700 stars
      hemisphere + ambient + key/fill directional lights
      resize listener
  → await document.fonts.ready
  → buildRoute()
  → buildGroundAndViaduct()
  → buildCity()
  → buildStations()
  → buildLandmarks()
  → buildTrain()          (also initRain(), initDynamicPassengers())
  → buildHUD()
  → initAudio()
  → bindEvents()
  → finishBoot()
```

`finishBoot()` reads the URL (`station`, `tod`, `rain`, `view`, `autostart`, `auto`, `selftest`), puts the train at Siam when no valid station is given, selects the intro or autostart path, minimises telemetry at ≤ 900 px, renders the 47-row station list, updates the HUD and starts `requestAnimationFrame(animate)`.

The loading copy is stepped by `setLoading(pct, copy)` at 6/18/32/48/64/76/86/93/100 percent. Each heavy builder yields one frame first (`await nextFrame()`), which keeps the loading bar visible.

## Coordinate system and route survey

- Y is up. The route lives in the XZ plane (`FORWARD_Z = (0,0,1)`); all track geometry sits at `TRACK_Y = 5.2`.
- `WORLD_PER_M = 0.25`: one displayed metre is a quarter of a world unit. `displayTotal = routeLengthWorld / WORLD_PER_M`.
- `routeCurve` is a `THREE.CatmullRomCurve3` through 39 hand-placed control points from `(0,-3700)` to `(-968,2800)`, tension `0.36`, not closed. The measured release curve is ≈ 7,221.8 world units, so `displayTotal` is ≈ 28,887 display metres.
- Station chainages are **synthetic**: they preserve the real station order but weight spacing by zone.

```text
baseGap = { A: 1.22, B: 0.96, C: 0.82, D: 1.22 }
weight[i]   = baseGap[zone] * (0.88 + ((i * 7) % 5) * 0.055)
cumulative[i] = cumulative[i-1] + weight[i]
usable      = displayTotal - 160
chainage[i] = 80 + (cumulative[i] / cumulative[46]) * usable
u[i]        = clamp(chainage[i] * 0.25 / routeLengthWorld, 0, 1)
```

The first and last stations sit 80 display metres inside the curve ends. `stationPositions`, `stationTangents` and `stationNormal(i) = (tan.z, 0, -tan.x)` are derived once and reused by stations, landmarks, billboards, traffic and the platform camera.

Helpers: `routePointAtDisplay(m)`, `routeTangentAtDisplay(m)`, `stationPoint(i, offset, along)`, `routeDistanceSq(x, z)`.

## Scene construction

### Viaduct and ground (`buildGroundAndViaduct`)

- 17,000² ground plane at `y = -0.4`; Gulf plane to the south-east, a rotated river plane and a coast strip, each at a slightly different height with `polygonOffset`.
- Two 3.5 m footways at ±9.5, a 15.4 m dark `RoadUnderlay` at 0.12, the 15 m `SukhumvitRoad` at 0.28 and a translucent under-viaduct shade at 0.34. These heights stop the green ground showing through when the road loses a depth test.
- Ribbons are generated by `makeRibbon(width, y, color, opacity, offset)` along 700 segments of `routeCurve`; rails use `offsetRouteCurve` + `TubeGeometry`.
- Instanced curbs every 6 units, parapets every 4, piers and crossheads every 28, sleepers every 3, third-rail cover boards every 6.
- Two running rails at ±0.18 and the glowing `ThirdRail` at +1.16 (`TRACK_Y + 0.34`), named for the self-test.

### City (`buildCity`)

`STATIONS.forEach` places `ZONES[zone].count` buildings per station (34 / 62 / 48 / 40 attempts) in a band `near..far` on both sides. Each candidate is rejected if `routeDistanceSq(x,z) < (13 + max(w,d) * 0.7)²`. Zone rules choose dimensions, palette and glass probability; tall buildings get roof slabs and antennas. Geometry is accumulated into `THREE.InstancedMesh` buckets (`buildingMesh`, `lowriseMesh`, `glassMesh`, `roofMesh`, `antennaMesh`). Windows come from `makeFacadePair` canvas textures (192×384 diffuse + emissive lit map).

After the buildings: `buildTrees(treeList)`, `buildStreetlights()`, `buildBillboards()`, `buildParks()`, `buildTraffic()` (46 cars on the road ribbon with random lane and direction).

### Stations (`buildStations`)

Each station is a group `Station_<code>` at `(stationPositions[i].x, TRACK_Y, z)`, rotated to `stationTangents[i]`. Both sides get:

- platform slab at ±3.72 (`y 0.17`), tactile strip at ±2.56 (`y 0.275`);
- 8 slatted canopy panels (4.25 pitch) and a ridge at 4.18/4.3; green fascia at 3.98; interchange stripe if present;
- inner/outer name boards from `makeStationSign`;
- 3 canopy columns, 2 lamps, 2 benches per side;
- a signal head appended to `stationSignals` (47 total); waiting pedestrians are pooled and passed to `buildPedestrians`.

### Landmarks (`buildLandmarks`)

Named groups are created by dedicated functions: `createVictoryMonument`, `createSiamSkywalk`, `createTerminal21`, `createBenchasiri`, `createErawanMuseum`, `createChatuchakSign`, `createKhuKhotDepot`, `createKhehaTerminus`, `createWatPhraSriMahathat`, `createPhayaThaiARL`, `createSamrongYellow`, `createPakNamDelta`, `createKasetsart`, `createThongLoNeon`, `createAsokMRT`. Helpers `addBox`, `addCylinder`, `addGlassBox`, `addSignBoard` keep them procedural. The first four are looked up by name in the self-test.

### Train (`buildTrain`)

Four `THREE.Group` cars (`BTS_Car_1..4`) at `CAR_LEN = 5.2`, `CAR_GAP = 0.55`, `CAR_PITCH = 5.75`. Materials: white body `0xf3f5f1`, blue lower `0x1c4f9c`, red cab frame `0xc8102e`, gold `0xf2c94c`, black window band, dark glass. Each car carries body, skirt, blue band, window band, doors (2 leaves per side), interior seats/poles, bogies, wheels, current-collector shoes, roof air-conditioning, headlights/tail lights and LED destination textures. `doorPanels` collects the sliding leaves; `headlightMats` and `headlightSprites` are dimmed per time of day. Front destination swaps between `destSouth` and `destNorth` with `state.direction`.

`updateTrainTransform()` samples the curve at `base = state.distance * 0.25`, then offsets car `c` by `-direction * c * 5.75`, clamps to the curve and orients each car with `setFromUnitVectors(FORWARD_Z, tangent)`.

### Rain and passengers

- `initRain()` creates 900 `LineSegments` streaks in a ±105 box; `updateRain(dt)` falls them, respawns above, follows the lead car and schedules lightning every 8–18 s.
- `initDynamicPassengers()` pools 28 six-part pedestrians; `spawnPassengerExchange()` assigns alighting and boarding walks when doors open; `updateDynamicPassengers(dt)` lerps position and swings limbs.

## Frame loop and data flow

```text
animate(now)
  dt = clamp((now - lastFrame)/1000, 0, 0.05)
  if started: updateKinematics(dt) → updateDoors(dt) → updateAudio(dt)
  else:       updateDoors(dt)
  updateTraffic(dt)
  if rain: updateRain(dt)
  updateDynamicPassengers(dt)
  updateTrainTransform()
  updateCameras(dt)
  updateSignalLights()
  updateBillboards(dt)
  if ready:
    every 0.10 s: updateHUD(false)
    every 0.22 s: updateMinimap()
  renderer.render(scene, camera)
  requestAnimationFrame(animate)
```

`state.time` accumulates real seconds and drives blinking, HUD throttles and camera bob. There is no physics engine; all motion is closed-form along the curve.

## Kinematics, auto pilot and doors

Manual (`manualDrive`):

```text
emergency: speed -= 11.5 * dt
brake:     speed -= 5.2 * dt
doors open or doorAnim > 0.04: speed -= 5.2 * dt
speed < throttle: speed += 4.2 * dt (capped at throttle)
speed > throttle: speed -= 0.85 * dt (coast)
clamp 0..100
```

Auto (`autoDrive`) has states `idle | run | dwell | closing | closingAnnounce`:

1. If doors are open: hold at 0; in `dwell`, count down `DWELL_SECONDS = 16`; then `closeDoors(true)`.
2. If `closing` and `doorAnim < 0.03`: release the station, reverse at a terminus, else depart.
3. At a station under 0.4 km/h and not speaking: `openDoors(true)`, set dwell.
4. Otherwise target speed: under 15 m creep at `max(2.2, dist * 0.8)`; beyond that `min(80, sqrt(2 * 1.2 * (dist - 12)) * 3.6)` with a 3 km/h floor.
5. Arrive when `dist < 5` and speed `< 2.8`.

`updateKinematics` integrates `metres = speed / 3.6 * dt`, clamps to `[0, displayTotal]`, updates `currentIndex` / `nextIndex`, announces when the next station changes, and applies two safety snaps:

- auto, speed `< 3.2`, distance to next `< 6 → stop and arrive;
- speed `< 0.45`, distance `< 1.5 → arrive.

Doors: `doorAnim` moves at 2.3 units/s. `isAtPlatform()` is true within 26 m and below 1.2 km/h. `openDoors` refuses while moving or away from a platform; both open and close queue through `state.pendingDoorAction` when `speechBusy` is true. Closing always plays the Thai/English stand-clear announcement and three door beeps.

## Camera pipeline

`setView(view, silent)` clamps 1–4, swaps `body.view-1..4`, toggles the active button, enables OrbitControls only for view 3, resets cab yaw/pitch, and seeds the orbit position behind the lead car.

| View | Rig in `updateCameras` |
| --- | --- |
| 1 Cab | lead car + forward 2.12 + y 1.92; look 100 forward and −0.18 down; bob by speed; FOV `62 + speed * 0.16`; drag adds `cabYaw` / `cabPitch` |
| 2 Window | car 2 + right 1.17 + y 1.62 + forward 0.9; look right 30, forward 72, up 9; FOV 58 |
| 3 Orbit | target lead + y 1.4; camera translates by target delta, `controls.update()`; distance 8–220 |
| 4 Platform | next station + normal 4.6 + tangent ±12; y `TRACK_Y + 3.2`; look at lead + 1.25; FOV `clamp(66 - dist * 0.018, 40, 66)` |

`setCameraFov(value, dt)` eases with `1 - exp(-5 dt)`. Camera lerps use `1 - exp(-k dt)` so behaviour is frame-rate independent.

## HUD, station list and minimap

- `cacheDom()` caches ~90 IDs; any new UI element must be added there or its handler will throw.
- `updateHUD` runs at 10 Hz and writes speed ring (`--pct`), mode/door/signal chips, traction bars, next station EN/TH, distance (`formatDistance`), ETA (`formatEta`), zone label/description, interchange chips, landmark, announcement banner, cab overlay, auto-pilot hint, body class `is-moving`, station-list classes and control states.
- `renderStationList()` creates 47 buttons; `updateStationListClasses()` tracks the focus station and scrolls it into view only when it changes (`state.lastStationList`).
- `updateMinimap()` draws the 280×170 canvas: route polyline, zone-coloured segments, 47 dots, train marker and current-station label.

## Audio pipeline

`createAudioEngine()` returns an object with one `AudioContext` and this graph:

```text
engineBus (state.engineVolume)
paGain    (state.paVolume)      ─┐
musicGain (state.musicVolume)    ├→ master (0.75) → DynamicsCompressor → destination
rainGain                         ┘
```

- Motor: sine 180 Hz + triangle 360 Hz → bandpass 620 Hz (Q 0.55) → gain. `setSpeed` maps frequency `170 + kmh*3.2`, `340 + kmh*6.4`, filter `540 + kmh*3`, and a separate 900 Hz whine `820 + kmh*6.8`.
- Brake squeal: looped noise → bandpass 1900 → gain, only above 4 km/h while braking.
- Thud: lowpass 150 noise burst every 13 display metres (`state.travelled / 13`).
- Chimes: PA is C5–E5–G5 (523.25/659.25/783.99); door is E5–A5.
- Horn: two sawtooth oscillators at 311/370 Hz through a 1000 Hz lowpass.
- Music: `patternA` / `patternB`, 16 pentatonic notes, one step every 620 ms, with octave and pad notes.
- Rain and thunder: filtered noise beds; lightning calls `audio.thunder()` after 260 ms.

PA: `speakAnnouncement(thText, enText, onDone, thaiKey)` waits 900 ms, then plays Thai first (`playThaiClip` from `audio/th/<key>.m4a`, falling back to `speechSynthesis` `th-TH`), then English via `speechSynthesis` `en-GB` at rate 0.94. The PA language selector (`both | th | en`) chooses the passes. A token guards against stale callbacks; `state.speechBusy` gates doors.

## Bilingual copy

- Static labels: `data-i18n="key"` in `index.html`, filled by `setLanguage`.
- Dynamic strings: `t(key)` plus `fill(template, {vars})`.
- Data-level copy: `STATIONS[i].en/th/landmark/landmarkTh`, `ZONES[zone].label/th/desc/thDesc`, `INTERCHANGES` + `INTERCHANGES_TH`.
- The top announcement always shows an English line and a separate Thai line (`#announceDetailTh`), independent of the selected UI language.
- There is no automated EN/TH key-parity check. The self-test only asserts that `setLanguage('th')` and `setLanguage('en')` update `#modeChip`.

## State and persistence

`state` (runtime only) holds: `ready`, `started`, `lang`, `view`, `tod`, `muted`, the three volumes, music/PA/voice/tourist flags, speech bookkeeping (`speechTimer`, `speechToken`, `speechBusy`, `pendingDoorAction`, `doorsClosingPending`, `thaiAudio`, `lastSpeech`), rain/lightning, speed/throttle/brake/emergency/auto, doors (`doorsOpen`, `doorAnim`), position (`distance`, `direction`, `currentIndex`, `nextIndex`, `atStation`, `dwell`, `travelled`), auto state, cab yaw/pitch/drag, intro mode, orbit vectors, and HUD throttles.

Persisted: **audio preferences only**.

```text
key: bts_audio_v1
{
  engine: number 0..1,
  pa: number 0..1,
  voice: boolean,
  tourist: boolean,
  music: number 0..1,
  musicEnabled: boolean,
  paLang: 'both' | 'th' | 'en'
}
```

Loaded by `loadAudioSettings()` during `initAudio()`; saved by `saveAudioSettings()` from every mixer control. Both are wrapped in `try/catch`, so blocked storage degrades silently.

## Invariants and non-obvious formulas

1. **Curve → display metres**: `displayTotal = routeLengthWorld / 0.25`; every position is `distance * 0.25` world units. The train, cars, stations and camera rigs all read the same conversion.
2. **Station sampling**: chainage is converted back with `u = chainage * 0.25 / routeLengthWorld`; do not sample stations by index (`i / 46`), or zone weighting and platform spacing break.
3. **Auto braking**: `sqrt(2 * 1.2 * (dist - 12)) * 3.6` km/h, capped at 80, with a 15 m creep rule. The 12 m buffer and 5 m arrival window are what stop the train on the mark without overshoot.
4. **ETA**: `dist / (speed / 3.6)` moving; `sqrt(2 * dist / 1.2)` from rest. Same `AUTO_DECEL` as the auto pilot, so the HUD and the train agree.
5. **Time of day** (`setTimeOfDay` presets): day fog 380–2700, dusk 150–1350, night 110–1100; exposure 0.76/0.78/0.72; building emissive 0.055/0.5/0.92; glass 0.12/0.48/0.62; neon 0.82/1.25/1.45; headlights 0.9/2.0/3.2. Storm (`applyStormLighting`) overrides fog to 90–980 and exposure to 0.76.
6. **Surface stack** (lowest to highest): ground −0.4, water −0.2, coast −0.1, road underlay 0.12, sidewalk 0.16, road 0.28, shade 0.34, viaduct deck 5.2, platform 5.37 (`TRACK_Y + 0.17`), tactile 5.475. Changing one requires re-checking the canopy-post area at grazing angles.
7. **Door interlock**: `DOOR_INTERLOCK = 0.04` blocks traction until the leaves are nearly shut; `isAtPlatform()` is 26 m / 1.2 km/h.
8. **PA-first**: `speechBusy` + `pendingDoorAction` is the only door queue. Auto dwell starts only when `!speechBusy && !doorsClosingPending`.

## Debug surface

`window.__BTS__` exposes `scene`, `camera`, `renderer`, `routeCurve`, `state`, `STATIONS`, `ZONES`, `INTERCHANGES`, `cars`, `audio`, `dynamicPeds`, `rainRoot` and the functions `setStation`, `setView`, `setAuto`, `setLanguage`, `setTimeOfDay`, `setRain`, `stationAnnouncement`, `openDoors`, `closeDoors`, `toggleDoors`, `updateHUD`, `runSelfTests`. Use it for CDP checks; it is not a public API. `window.__BTS_ERRORS` is populated by a global error listener, and `window.__BOOT_ERROR` records a caught boot failure.

## Extension points

- **Add a station** — append one row to `STATIONS` in correct geographic order, update the count assertions (47 → 48) and any README/help copy, and add matching PA clips (`next-<code>.m4a`, `next-<code>-brief.m4a`, `arr-<code>.m4a`) or accept TTS fallback. Do not renumber; chainage derives from array order.
- **Add a camera** — add a `data-view` button and CSS overlay, add the ID to `cacheDom`, extend `setView` and `updateCameras`, and bump the "Four camera views" self-test. Controls are only enabled for view 3.
- **Add a landmark** — write a `createX()` returning a named `THREE.Group`, call it from `buildLandmarks()` via `landmarkGroup(stationIndex, offset, along, name)`, then add a name lookup to the self-test if it is release-critical.
- **Add a PA line** — add a Thai text + English text pair and a clip key; `speakAnnouncement` handles ordering and door gating. Keep the filename convention; `playThaiClip` prepends `audio/th/`.
- **Tune physics** — change the constants at the top of `script.js` and re-check the auto pilot over several stations, including a terminus reversal. The ETA and braking target share `AUTO_DECEL`; do not change one alone.
- **Change the route** — edit the 39 control points, then re-check station spacing, building clearance, billboard placement, platform camera framing, and the first/last 80 m margins. Screenshots and the `state.json` measurements become stale.
